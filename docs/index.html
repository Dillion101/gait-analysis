01 / THE QUESTION

Recognition begins
before the model.

A gait cycle may contain dozens of silhouette frames. A feature representation compresses that sequence into a form a classifier can learn - but every compression preserves some signals and discards others.

This project asked which representations carry the most useful identity information, and whether combining static shape with dynamic movement could improve recognition.

Research hypothesis

Representations that preserve both appearance and temporal change will outperform methods that isolate either signal.

WHAT THE REVIEW CHANGED

GEI was dominant and efficient, but repeatedly associated with information loss. GEnI captured variability; GFI captured motion but at higher computational cost. That tension led us first to compare representations under matched classifiers - and then to combine complementary cues through DEWGI and the GaitSTAR adaptation.

WHY TWO CLASSIFIERS?

Testing every representation with two different CNN families helped us ask whether performance came from the input representation or depended on one particular architecture.

DENSENET

Reuse what earlier layers learned.

DenseNet connects each layer to later layers, encouraging feature reuse and stronger gradient flow. In our matched experiments it achieved the higher accuracy and lower cross-entropy loss for all five representations.

BEST PAIR · DEWGI 92.34% · LOSS 0.27
RESNET

Learn corrections through shortcuts.

ResNet uses residual connections so deeper blocks learn adjustments to an identity path. It provided a second architectural test of each representation and also ranked DEWGI first.

08 / REPRODUCIBILITY RECORD

What the notebooks let us reconstruct.

This record comes from executable cells, saved outputs, and notebook metadata - not retrospective estimates. Open each panel for the exact experimental choices and known limitations.

01Data and split＋

GEI, GEnI, GFI, and DEWGI contain 8,155 derived images; MSI and Enhanced GaitSTAR record 8,154. Images were grayscale at 240×240 with 124 identity labels.

  • 80/20 row-level random split
  • random_state=42 for splitting
  • 6,524/1,631 samples for most methods
  • 6,523/1,631 for MSI and GaitSTAR
  • Training-mean centering applied to test data
02DenseNet recipe＋

All five representations used the same DenseNet training function for the matched comparison.

  • Adam, learning rate 0.0001
  • Categorical cross-entropy
  • Batch size 32; maximum 50 epochs
  • Rotation ±10°, width/height shifts 0.1, horizontal flips
  • Early stopping on holdout accuracy, patience 10
03ResNet recipe＋

The ResNet experiments used a residual image classifier with checkpoints and scheduled learning rates.

  • Adam, initial learning rate 0.001
  • Categorical cross-entropy
  • Batch size 32; 100 epochs
  • Learning-rate schedule plus ReduceLROnPlateau
  • Best checkpoint selected by holdout accuracy
04Enhanced GaitSTAR recipe＋

The final PyTorch model used the enhanced residual-attention architecture documented above.

  • Batch size 32; 150 epochs
  • AdamW, learning rate 0.001, weight decay 0.05
  • Label smoothing 0.1
  • Cosine OneCycle learning-rate schedule
  • Auxiliary loss weight 0.4; gradient norm capped at 1.0
05Environment and limitations＋

The notebooks record Python 3.10.14, Kaggle GPU runtimes, CUDA execution, and Tesla T4 acceleration for most DenseNet/ResNet runs. Kaggle image IDs range from 30775 to 30787.

  • Exact TensorFlow, PyTorch, and CUDA package versions were not printed
  • No global NumPy/TensorFlow/PyTorch training seeds were set
  • The holdout set was used for monitoring and final evaluation
  • Enhanced GaitSTAR saved the epoch with the best holdout/test accuracy
  • This means results are reproducible in structure, but not guaranteed bit-for-bit

GUIDED WALKTHROUGH · 1 / 6

The question came first.

Could the way a walking sequence is compressed determine how well a neural network recognises the walker? That question connected our literature review, feature experiments, and final model.

 A 60-SECOND INTRODUCTION

What is gait?

Gait is the characteristic way a person walks. It contains patterns in posture, rhythm, stride, and limb movement that can help distinguish one walker from another.

01
Record the walk

A camera captures a short sequence of someone walking from a particular viewpoint.

02
Keep the silhouette

Each frame is reduced to the person’s outline, limiting distractions such as clothing colour and background detail.

03
Compress the movement

Multiple silhouettes become one feature image. Our study compared five ways to create that image.

04
Learn the identity signal

DenseNet and ResNet tested the feature images, followed by our work to enhance GaitSTAR.

What this project was not: a medical diagnosis system. It studied biometric identification using normal walking sequences from the CASIA-B dataset.
